# solution1: cannot copy the connected CKB address in the web UI

## Description

After connecting a wallet to [CKB Treasury Web (testnet)](https://treasury-testnet.ckbapp.dev/), the top-right corner only shows a shortened CKB address, with no copy functionality. BTC wallets such as UniSat display a BTC address in their own interface, making it difficult for users to obtain the corresponding full CKB address.

Whenever I need the full CKB address, such as to look up transactions by address on [CKB Explorer](https://testnet.explorer.nervos.org/) or request testnet CKB from [Nervos Pudge Faucet](https://faucet.nervos.org/), I have to connect the same wallet to [CCC App](https://app.ckbccc.com/) to view and copy the corresponding address. Relying on another app just to obtain the address makes these common tasks inconvenient.

# solution1: 网页无法复制已连接账户的 CKB 地址

## 问题描述

在 [CKB Treasury Web（测试网）](https://treasury-testnet.ckbapp.dev/) 连接钱包后，右上角只展示缩略 CKB 地址，缺少复制功能。使用 UniSat 等 BTC 钱包时，钱包内显示的是 BTC 地址，用户无法方便地取得对应的完整 CKB 地址。

每次需要完整的 CKB 地址时，例如在 [CKB Explorer](https://testnet.explorer.nervos.org/) 按地址查询交易或在 [Nervos Pudge Faucet](https://faucet.nervos.org/) 领取测试币，我都得先在 [CCC App](https://app.ckbccc.com/) 连接同一个钱包，才能查看并复制对应地址。仅仅为了获取地址就要借助外部应用，让这些常见操作变得不方便。
